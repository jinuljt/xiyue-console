大模型 LLM

  1. 到对应平台开通模型调用并创建 API Key。
  2. 在喜悦的「系统配置」选择厂商，检查服务地址，再选一个模型或输入账号可调用的模型 ID。
  3. 粘贴 API Key，保存配置，点击「发送文字验证」。收到回复后，首次引导会自动隐藏。

如果鉴权失败，检查密钥与所属项目或地区。在「模型预设」可浏览喜悦内置的选项。除此之外，可在「模型 ID」输入厂商提供的 ID。模型找不到时，确认账号或套餐已开通该模型。

语音识别 ASR

设备端语音启用后，可选择豆包语音或自建 SenseVoice。

豆包语音识别

在火山引擎开通豆包流式语音识别 2.0。在豆包语音控制台「API Key 管理」创建密钥，回到喜悦选择「豆包语音（云端）」，填写密钥并选与开通方式对应的资源 ID。默认是小时版 volc.seedasr.sauc.duration。喜悦在用户说完后提交当前语音片段。一句话识别接口文档

自建 SenseVoice

在常开的机器上按 FunASR 文档启动 SenseVoice HTTP 服务，先用示例音频验证。把以 /v1 结尾的 Base URL 填入控制台「语音识别」。喜悦会在该地址追加 /audio/transcriptions，使用 sensevoice 模型别名。启用认证时使用 HTTPS。FunASR HTTP 服务部署说明

语音合成 TTS

默认使用音箱系统语音，无需额外账号或密钥。设备端语音启用后，语音请求的模型回复由系统服务播报。

豆包语音合成将在适配完成后开放。届时请在火山引擎开通对应合成服务，按同一个接口版本获取凭证并选择音色。豆包语音文档

连接已有助手

如果你已经在用 Codex，可以把指定工作区里的查询交给它处理。先在 Codex 所在机器运行喜悦连接器。

  1. 按安装文档启动连接器，绑定工作区并配置访问凭证。
  2. 在喜悦的「系统配置 → 高级接入」可选「仅使用外部 Agent」或「大模型 + 外部 Agent」。
  3. 填入以 /v1/chat 结尾的完整地址及连接器凭证。跨设备使用时填 HTTPS 地址。
  4. 保存后，发送一条文字验证，例如请 Codex 概括这个工作区的用途。长任务可在「任务与待办」里提交、查看结果或请求取消。

组合模式下，普通问答由大模型处理。需要委托时可说「交给外部助手，概括这个工作区的用途」。
