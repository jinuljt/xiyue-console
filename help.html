大模型 LLM

  1. 到对应平台开通模型调用并创建 API Key。
  2. 在喜悦的「系统配置」选择厂商，检查服务地址，再选一个模型或输入账号可调用的模型 ID。
  3. 粘贴 API Key，保存配置，点击「发送文字验证」。收到回复后，首次引导会自动隐藏。

如果鉴权失败，检查密钥与所属项目或地区。模型找不到时，从服务商后台复制模型 ID，再确认账号已开通该模型。

语音识别 ASR

喜悦的语音识别适配尚未开放，准备服务后请等待对应选项上线再填写凭证。

豆包语音

在火山引擎开通流式语音识别，按所选接口的鉴权说明创建凭证，并记录使用的资源 ID。流式语音识别文档

自建 SenseVoice

在常开的机器上按项目文档下载并运行 SenseVoice，先用示例音频确认识别正常。喜悦将为验证过的服务部署方式补充接口地址和认证步骤。SenseVoice 官方运行说明

语音合成 TTS

默认使用音箱系统语音，无需额外账号或密钥。音箱端播报接入后可试听。

豆包语音合成将在适配完成后开放。届时请在火山引擎开通对应合成服务，按同一个接口版本获取凭证并选择音色。豆包语音文档

连接已有助手

如果你已经在用 Codex，可以把指定工作区里的查询交给它处理。先在 Codex 所在机器运行喜悦连接器。

  1. 按安装文档启动连接器，绑定工作区并配置访问凭证。
  2. 在喜悦的「系统配置 → 高级接入」选择「仅使用外部 Agent」。
  3. 填入以 /v1/chat 结尾的完整地址及连接器凭证。跨设备使用时填 HTTPS 地址。
  4. 保存后，发送一条文字验证，例如请 Codex 概括这个工作区的用途。
