语音识别 ASR

选择豆包语音或自建 SenseVoice，填好后点击「验证」，再对音箱说一句话。控制台会显示识别结果。

豆包语音识别

在火山引擎为项目开通豆包流式语音识别 2.0 小时版，按识别时长计费。在该项目的「API Key 管理」创建密钥，回到喜悦选择「豆包实时语音识别」，填写密钥并点击「验证」。喜悦边录边发，说完后将最终识别文本交给 Agent。若验证返回 HTTP 403，请核对 API Key 所属项目是否已开通小时版。实时语音识别接口文档

自建 SenseVoice

在常开的机器上按 FunASR 文档启动 SenseVoice HTTP 服务，先用示例音频验证。把以 /v1 结尾的 Base URL 填入控制台「语音识别」。喜悦会在该地址追加 /audio/transcriptions，使用 sensevoice 模型别名。启用认证时使用 HTTPS。FunASR HTTP 服务部署说明

语音合成 TTS

DeepSeek 有海星和暗潮两种音色，自动从文本识别语种。为语音合成填写 DeepSeek API Key 后，可选语言并试听。音箱自带语音可试听英文、日文和韩文，实际兼容性以该型号和固件的试听为准。

DeepSeek 语音合成官方文档

默认使用音箱系统语音，无需额外账号或密钥。点击「验证」可让音箱播报一句测试语。设备端语音启用后，语音请求的模型回复由系统服务播报。

如需更换音色，在豆包语音开通语音合成模型 2.0，从音色库复制音色 ID。回到喜悦选择「豆包语音合成」，填写音色和对应的豆包语音 API Key。此选项需要设备提供 PCM 播放。播报时会将文字发送到豆包语音。豆包语音合成官方文档

对话语言与外语陪练

让喜悦用其他语言回答

  1. 进入「系统配置 → 语音与语言 → 语音合成」。系统语音当前只开放普通话对话，其他语言可在系统语音的「试听」中验证。
  2. 选择支持目标语言的服务和音色。例如英语或日语可用 DeepSeek 的海星、暗潮，或豆包的 Vivi 2.0。按语音合成指南填写 API Key 并试听。
  3. 在同一页「对话语言」选择默认回答语言，保存语音设置。直连模型或混合模式下，也可以在某一轮说「这题用英文回答」。

语音合成设置与密钥说明

和喜悦练习口语

  1. 配置能识别目标语言的 ASR。英语可用豆包实时识别或自建 SenseVoice。日语、韩语、粤语可用自建 SenseVoice。
  2. 换用能播报同一语言的音色。例如日语可用 DeepSeek 或豆包 Vivi 2.0，韩语和粤语可用 DeepSeek。验证后保存语音设置。
  3. 在「系统配置」启用直连大模型或混合模式，再进入「能力中心 → 外语陪练」，选择语言并启用。

说「陪我练口语，模拟点咖啡」即可进入陪练。说「退出陪练」可回到日常对话。

网页搜索与连接工具

网页搜索

在「系统配置 → 网页搜索」启用 DeepSeek。可以复用官方 DeepSeek 模型的凭证，也可以填写独立的 DeepSeek API Key。先点「验证」，再保存配置。启用后，喜悦可在需要最新信息时搜索，也能读取你指定的公开网页。独立接口的计费情况可在「用量」查看。

DeepSeek 官方接口与计费说明

Home Assistant

在 Home Assistant 的个人资料页创建长期访问令牌。在「能力中心 → Home Assistant」填写服务根地址和令牌。保存连接后，选择一个实体和要开放的操作。读状态可开放给语音，灯和开关的开关动作可添加到自动化。

自定义 HTTP 工具

「HTTP 测试工具」是一条预置的自定义工具。点「配置」查看示例地址、GET 方法和返回字段 args.message。点「试运行」会向 Postman Echo 发送固定参数并显示 hello。你可以修改或移除这条工具。Postman Echo 接口说明

填写固定地址、用途、GET 或 POST，以及接口需要的参数。GET 参数会附到 URL 的查询字符串，POST 参数会作为 JSON 对象发送。可以给每个参数选择文本、数字或布尔值。试运行时填写示例，可直接查看返回；如只想读取某一项，在「响应设置」填写路径，例如 items.0.status 或 /items/0/status。留空保留完整响应。自动化使用原始类型，格式与单位可写在播报步骤中。

保存后，勾选允许语音调用的 GET 工具可在对话中使用。勾选开放给自动化后，可在规则中添加「调用连接工具」并填写该规则的参数值。语音调用时，所选的工具返回内容会传给已配置的对话模型整理。

编排自动化

  1. 进入「自动化 → 新建自动化」，选择手动、到指定时间，或 Home Assistant 设备状态变化。
  2. 按需要限制执行时段或远程听音状态。时段以音箱时区为准，可以跨午夜。
  3. 添加并排序执行步骤。「等待一段时间」结束后自动执行下一步。「启动响铃倒计时」创建独立倒计时，流程继续执行。
  4. 点「预览」检查顺序。保存后点「立即运行」，可查看每一步的进度和结果。

可以用「播报并等待确认」做菜谱引导。提示播报后，点「确认并继续」或唤醒音箱说「继续下一步」。可设置确认后跳到后续步骤，以及超时后继续或停止。

配置设备触发前，在 Home Assistant 能力中添加对应实体的「读取状态」工具，勾选允许自动化调用。填写触发值，例如开门时变为 on。音箱约每 10 秒读取一次设备状态，连接后的第一次读数用于确定初始状态。

复用或迁移流程

在流程行点「导出」，再通过「导入流程」打开文件。导入后会在同一编辑器打开副本，检查后再保存。换音箱时，工具和设备要在本机先配置并授权，缺少的依赖可在编辑器里重新选择。文件包含流程文字和参数，运行记录和服务凭证保存在设备上。

在下一步使用 HTTP 结果

在「调用工具」里填结果变量名，例如 order。在「判断变量」选择 order.status，输入要比较的文本和不匹配时的跳转目标。在「播报文字」可填 订单状态是 {{order.status}}，其他工具参数也能引用变量。结果变量只在本次流程运行中使用。

音箱重启时，流程中的执行会记为中断。远程听音如果处于开启状态，会独立恢复。

连接已有助手

如果你已经在用 Codex，可以把指定工作区里的查询交给它处理。先在 Codex 所在机器运行喜悦连接器。

  1. 按安装文档启动连接器，绑定工作区并配置访问凭证。
  2. 在喜悦的「系统配置 → 模型与助手 → 高级接入」可选「仅使用外部 Agent」或「大模型 + 外部 Agent」。
  3. 填入以 /v1/chat 结尾的完整地址及连接器凭证。跨设备使用时填 HTTPS 地址。
  4. 填好连接器地址后可直接点击「验证」，确认可用后再保存。长任务可在「任务与待办」里提交、查看结果或请求取消。

组合模式下，普通问答由大模型处理。需要委托时可说「交给外部助手，概括这个工作区的用途」。
