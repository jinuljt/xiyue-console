喜悦控制台 · 网页管理

控制台是独立的静态前端，随设备端服务分发，通过同源 HTTP API 管理任务。当前为开发预览，所有提示仅显示文字。

可用页面

  • 总览：任务、可用能力、计划数量和最近提示。
  • 能力库：配置、启用/停用、导入声明式 JSON。
  • 任务与待办：确认、暂停、继续、取消、查看计时。
  • 定时计划：一次性、每天、工作日执行。
  • 设备与服务：明确显示尚未接入的语音与模型服务。

开发

node --check app.js
# 从 xiyue-agent 启动：
go run . -console ../xiyue-console

无需前端依赖或构建工具。页面须由 Agent 提供，不直接双击 index.html。通过原生 dialog 和表单呈现配置，用户与插件内容均以 textContent 插入。轮询获取状态，倒计时只作为显示，最终执行以 Agent 为准。

边界

不持有定时器业务、不直接调用厂商 API、不保存真实密钥。credential_ref 暂时是凭证引用表单，尚非面向普通用户的密钥配置完成态。模型、ASR、外部 Agent、配对与托管服务页面在对应后端完成后接入。
