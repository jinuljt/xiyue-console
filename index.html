    远程听音

    用安卓手机上的 IP Webcam 收音，喜悦音箱实时播放。

    1. 让手机和音箱连到同一网络。打开 IP Webcam 下载页。
    2. 打开 IP Webcam，允许使用麦克风，滑到页面底部点「启动服务器 / Start server」。
    3. 复制手机上显示的地址，后面加上 /audio.wav，填到下方并点「验证连接」。

    其他应用也可用，前提是能提供局域网 HTTP WAV 直播地址。音箱只进行实时播放。
